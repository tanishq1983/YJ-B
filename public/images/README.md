# 📸 Put your photos here

Drop 1–6 photos of Yukti in this folder, then list them in
`src/config.js` → `config.photos` (file name, caption, tilt).

Suggested names (matching the current config):
- `yukti-1.jpg`
- `yukti-2.jpg`

If a photo listed in the config is missing, the site shows a cute
hand-drawn placeholder instead of a broken image — so nothing breaks
while you're still choosing photos.

JPG / PNG / WebP all work. Landscape or portrait is fine; the
polaroids crop gently to 4:5.
